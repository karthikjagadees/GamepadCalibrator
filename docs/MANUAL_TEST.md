# Manual hardware test procedure

1. Connect controller, launch app, select device.
2. Raw Axes: confirm at least one axis changes when moving a stick.
3. Axis Discovery completes without crash; warnings are readable.
4. Left stick live dot moves for each working axis.
5. Buttons light PRESSED for every physical button.
6. D-pad shows UP/DOWN/LEFT/RIGHT/diagonals.
7. Save profile, unplug, replug → profile auto-loads.
8. Reset Calibration restores unassigned mapping after confirm dialog.
9. Final Validation summary marks missing axes with ⚠, not false ✓.

Record PASS / WARNING / FAIL per stick, hat, and buttons.
